# iGUIDE — Brand Color Scheme & Logo Proposals Guide

**Official System Name:** **iGUIDE** — *Interactive Geospatial Unified Information Directory and Explorer*  
**Agency:** Department of Agriculture – Regional Field Office IV-CALABARZON (PMED–MIS Unit)

---

## 1. Recommended Color Schemes (Minimalist & Cohesive)

A minimalist wordmark works best with **1 unified base ink color** across all letters (`iGUIDE`), and **at most 1 subtle accent color** on the 45° navigation pointer. Avoid splitting `i`, `GUIDE`, and the pointer into three different colors.

### Scheme A — Dark UI & Map Interface *(Primary App / Kiosk / Admin)*
| Element | Color Name | Hex | Usage |
| :--- | :--- | :--- | :--- |
| **Wordmark (`iGUIDE`)** | Crisp Off-White | `#F8FAFC` | Sidebar header, Welcome Modal, Admin Login |
| **Pointer Accent** | Warm Gold | `#FFD23F` | 45° navigation pointer above `i` |
| **Background Surface** | Deep Navy Slate | `#0A0F1C` / `#0B1120` | Map UI, Kiosk panels, Admin backdrop |
| **Secondary UI Accent** | Emerald | `#10B981` | Active pills, buttons, route highlights |

### Scheme B — Light Slides & Official Documents *(Canva / Print)*
| Element | Color Name | Hex | Usage |
| :--- | :--- | :--- | :--- |
| **Wordmark (`iGUIDE`)** | DA Forest Green | `#1B4D2E` | Title slides, headers, concept notes |
| **Pointer Accent** | DA Forest Green (or Warm Gold) | `#1B4D2E` / `#EAB308` | Single-color print or subtle gold highlight |
| **Background Surface** | Soft Off-White | `#F8FAF8` / `#FFFFFF` | Presentation slides & formal documents |

### Scheme C — Editorial Tech-Gov *(High-Contrast Light UI)*
| Element | Color Name | Hex | Usage |
| :--- | :--- | :--- | :--- |
| **Wordmark (`iGUIDE`)** | Deep Charcoal Slate | `#0F172A` | Clean modern reports & web headers |
| **Pointer Accent** | Emerald | `#10B981` | 45° navigation pointer above `i` |
| **Background Surface** | Pure White | `#FFFFFF` | Light-mode web pages & letterheads |

### Scheme D — Monochrome Fallback *(Stamps, Watermarks, Single-Ink Print)*
- **Light Background:** 100% `#063017` or `#0F172A`
- **Dark Background:** 100% `#FFFFFF`

## 3. Alternative Logo Style Proposals (For Presentation / Selection)

If proposing multiple logo directions to management alongside the minimalist wordmark:

1. **Style 1 — Minimalist Typography Wordmark (`iGUIDE` + 45° Pointer):**
   - *Concept:* Wordmark-only identity where a crisp geometric navigation dart replaces the dot on `i`.
   - *Strength:* Timeless, ultra-clean, zero visual clutter, animates subtly on the pointer.
2. **Style 2 — Pin-Leaf & Compass Star:**
   - *Concept:* A minimalist map pin + leaf silhouette forming an `i`, topped by a gold compass star next to `iGUIDE`.
   - *Strength:* Explicitly blends agriculture (leaf) and navigation (pin + compass).
3. **Style 3 — 3D Isometric Campus & Route Tile:**
   - *Concept:* Isometric emerald 3D plot/campus tile with a glowing `i` walking path leading to a gold destination pin.
   - *Strength:* Directly represents 3D buildings, research plots, and pedestrian routing.
4. **Style 4 — Orbital GPS & Sprouting Leaf Seal:**
   - *Concept:* Circular geospatial emblem combining GPS rings, a sprouting leaf, and a central `i`.
   - *Strength:* Classic government seal symmetry for official plaques, kiosks, and formal reports.
